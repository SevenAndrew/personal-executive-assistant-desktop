# PEA 0.16.0 — public preview

This is the first public source release of Personal Executive Assistant.

## Highlights

- Controlled Minutes generation from selected PLAUD transcripts.
- Rendered Markdown previews for Minutes, summaries and workflows.
- Explicit Agenda, reMarkable, work-chat and email source selection.
- Daily and weekly summary workflows.
- Duplicate-protected DEVONthink Inbox writes.
- Bounded OmniFocus reads and controlled Inbox captures.
- First-run dependency and authorisation assistant.
- System-health, API-usage and privacy-bounded diagnostics views.

## Validation

- Ruff checks passed.
- 106 automated tests passed.
- The macOS bundle was verified as an arm64 application.
- Ad-hoc code-signature and ZIP integrity checks passed.
- The public source tree and bundle were scanned for credentials, OAuth data, personal paths and
  private application content.

## Important limitations

- The downloadable macOS bundle is a pre-release build for Apple silicon and macOS 13 or newer.
- It is ad-hoc signed and not notarised because no Apple Developer-ID identity was available for
  this release. macOS may prevent it from opening.
- Users should not disable macOS security controls. Source installation remains available.
- Connected applications and their licences are not included.
- API usage incurs charges from the selected provider account.
- Transcriptions and generated output require human verification before operational use.
